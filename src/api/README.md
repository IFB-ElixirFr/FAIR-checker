# Fair-Checker API 

The Fair-Checker KG API is a REST API allowing to perform queries and requests to the knowledge graph without ever needing to write a SPARQL query.

It also allows to perform some maintenance routines on the graph like rebuilding 
the graph from scratch or adding the data of a report that has not been added to the 
graph yet 

## Development

To use the API in a development environment, first build the venv environment for the api.

```
bash
## in the api directory 
python3 -m pip install -r requirements.txt
```

When the environment is created, activate it and run the local flask server to launch the Fair-Checker API

```
bash
source .venv/bin/activate
python3 app.py
```

## Technical details

The Fair-Checker API relies on Flask.
